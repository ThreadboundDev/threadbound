# Threadbound Color & Palette System
## Base Values
- Colorless: `R=0.2, G=0.2, B=0.2`
- Choose starting color: `+0.4` to that channel → one = 0.6, others = 0.2

## Per-Boss Choice
| Choice | Effect on that channel |
|-------|-------------------------|
| Absorb | `+0.4`                 |
| Spare  | `–0.2`                 |

## Natural Outcomes

| Ending                     | Final Channels (start Red) | Visual Result                     |
|----------------------------|----------------------------|-----------------------------------|
| True Red / Blue / Yellow   | 1.0 / 0.0 / 0.0            | Pure saturated color              |
| Pure Mercy (spare all)     | 0.0 / 0.0 / 0.0            | Pure white → Reclaimer → SET WHITE |
| Pure Corruption (absorb all) | 1.0 / 0.6 / 0.6          | Overflow → Reclaimer → SET BLACK   |
| Hybrid                     | Any other mix              | Unique muted hybrids              |

## Reclaimer Secret Zone
- Unlocks **only** on Pure Mercy or Pure Corruption runs
- Choice must match your path:
  - Pure Mercy + Spare Reclaimer → **White Transcendence**
  - Pure Corruption + Absorb Reclaimer → **Black Devourer**
  - Inconsistent choice → **Instant Game Over** (Shattered / Hollow endings)

## Colorless Run (secret challenge)
- Never pick starting color
- Somehow reach end (extremely hard)
- Palette stays near 0.2 or fades/overflows
- Reclaimer interaction: TBD (maybe both choices kill you, or something cosmic)
