\# Core Mechanics



Threadbound’s movement is built on \*\*momentum chaining\*\* and \*\*thread-responsive traversal\*\* in a painterly 2.5D world. Every archetype feels completely different, but any pure starting color can finish the game.



\### Universal Tools (All Archetypes)

* Basic pogo bounce on enemies/traps/spikes (short range, Hollow Knight-style spike navigation).
* Basic Jump
* Free-form grapple (raycast to any collider, no fixed points, short range / slow).





\### Traversal Loop

\- Momentum builds from runs, swings, vaults.

\- Equipment transforms lanes (faster, safer, more expressive) but never gates progress.
