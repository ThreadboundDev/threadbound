\# Story Outline



1\. \*\*Opening Cinematic\*\* — Scrolling tapestry reveals history; Weaver shatters Loom; one thread falls.

2\. \*\*Awakening\*\* — Player (Threadborne) in Chamber of the First Weave.

3\. \*\*Starting Choice\*\* — Select Red, Blue, or Yellow → sets initial abilities + narrative tone.

4\. \*\*Exploration\*\* — Nonlinear regions in any order (Monarch's domain, Hermit's waters, Sage's libraries).

5\. \*\*Thread Masters\*\* — Confront each:

   - \*\*Spare\*\* → They live; positive world reactions later (allies, lighter tone).

   - \*\*Absorb\*\* → Gain secondary powers; world darkens (corruption visual/atmospheric shifts).

6\. \*\*Optional\*\* — Reclaimers’ Area (extreme challenge; lose thread temporarily for high-risk rewards/extreme endings).

7\. \*\*Climax\*\* — Return to ruined Grand Loom.

8\. \*\*Final Confrontation\*\* — The Weaver (fight adapts to absorptions).

9\. \*\*Endings\*\* — 8+ variations based on starting color + spare/absorb choices (True single-color, hybrids, black/white extremes, Reclaimers unlocks).



Tone remains melancholic/hopeful throughout — choices shown via environment, follower commentary, visual evolution.
