## Git and recovery boundary

`Tracked/` holds formerly tracked files. `Uncommitted/` preserves previously untracked files without silently adding them to the task commit. `LocalOnly/` preserves files that were already ignored locally; that portion stays ignored and is not backed up by a push. The manifest labels every file. The five organized Chamber sources remain versioned, with LFS attributes. Archived tracked bitmap/source art uses LFS.

Six archived tracked files already had local edits: the old woven tileset, three Eave Runner sprite sheets, its study manifest and the Woven Shore concept scene. Their exact saved contents are preserved in the archival checkpoint; this does not approve their art or gameplay. Unrelated staged deletions and all other working changes are kept separate.

Use the repository Python interpreter to run:

```powershell
python tools/maintenance/cleanup_review.py docs/organization/cleanup_manifest_2026_11_25.json --verify
```

To restore one reviewed file, use its exact original `source` path from the manifest:

```powershell
python tools/maintenance/cleanup_review.py docs/organization/cleanup_manifest_2026_11_25.json --restore --source "original/path/from/manifest"
```

The tool refuses changed files, overwrites, links and paths outside this repository. Restoration recreates original parent directories. It also supports a dry-run (omit the mode) and resumable `--apply`. The durable local journal is `tmp/cleanup-2026-11-25/moves.jsonl`. Restoring a historical scene can require restoring its archived companion assets as well.
