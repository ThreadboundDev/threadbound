# OG Base modeling pair

Use the [front](og_base_model_front.png) and [back](og_base_model_back.png) as two views of the same clean Base outfit. Use the original idle sprite for proportion decisions and the front reference for the final head scale and palette. The left bracer carries an empty leather harness for the separate rope and needle. The articulated hands share the head's ivory palette. The front boots show toe boxes and the back shows heel counters. The generated views are approximate modeling guides.

Both 1254 × 1254 PNGs are included in the ZIP with these notes and the [exact built-in ImageGen prompts](model_pair_prompts.json).
