# Bellstriker front and back generation references

November 9, 2026. Chase requested front and back images for a cleaner Bellstriker
generation candidate after discussing a spread neutral pose. Created with the
built-in image_gen tool using the existing Bellstriker model capture as reference.

## Deliverables

- `bellstriker_front_v1.png`: front/ventral view, neutral spread arms and legs.
- `bellstriker_back_v1.png`: matching rear/dorsal view derived from the front.
- `prompts.json`: full generation and correction prompts.

Both images have a plain light-gray background and show two large club arms,
eight separated small walking legs, four long antennae, and a tail fan. The
frontal presentation raises the body and points the abdomen down to expose the
limb attachments; it is a rigging reference pose, not a new locomotion direction.
The first front draft omitted one leg pair; the delivered front corrects that.

Visual review: complete silhouettes, separated limbs, matching broad proportions,
and distinct front/back shell surfaces. These are generated concept references,
not mathematically registered renders of one mesh. Fine plate details may differ.
The candidate cleans and interprets the existing arm connections; appearance
acceptance and any future model replacement remain pending.

Use the front as the main image and the back as its rear reference where supported.
Inspect any generated model for limb separation, joint construction and deformation
before considering it a replacement for the current rigged Bellstriker v4.
No live model, rig, animation, combat behavior, or worklist acceptance was changed.
