# Still Village runtime art

Twelve orthographic renders from editable Blender models; two image-generated
2D parallax plates; a presentation-only distance material; the rendered Hanging
Bell bulb atlas and four-state SpriteFrames resource.

Open `res://Src/Environment/BlueBiome/Prototypes/Rooms/blue_still_village_preview.tscn`
for the assembled test room. Placeable scenes are under
`res://Src/Environment/BlueBiome/ArtPlaceables/StillVillage/`.

Sources, regeneration instructions, animation timings, validation, and review
images are in `ArtSource/BlueBiome/Blender/StillVillage/README.md`.
The source renders have explicit pivots recorded in `kit_manifest.json`.
