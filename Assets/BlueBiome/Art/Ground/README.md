# Blue Biome Ground Tiles

`blue_lake_slate_terrain_v2.png` is a 4-by-5 atlas of 128 px tiles for the
natural, lake-worn terrain around the chamber exit and Blue Biome outskirts.
It is a Blue Biome skin of the Chamber of the First Weave's proven terrain
atlas: tile silhouettes, full-size corners, connection points, and terrain
peering rules match that set exactly.

Paint with the `Blue Lake Slate` terrain rather than selecting isolated atlas
cells. Godot will then choose the matching fill, edge, and corner pieces.

The atlas is intentionally terrain-only. Rooftops and village architecture use
their own free-placeable art so the terrain does not become repetitive or force
building silhouettes onto the collision grid.
