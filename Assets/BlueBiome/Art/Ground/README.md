# Blue Biome Ground Tiles

`blue_lake_slate_terrain_v2.png` is a 4-by-4 atlas of 128 px tiles for the
natural, lake-worn terrain around the chamber exit and Blue Biome outskirts.

| Atlas row | Tiles from left to right |
| --- | --- |
| 0 | Fill variations A, B, C, D |
| 1 | Top edge, bottom edge, left edge, right edge |
| 2 | Outer top-left, top-right, bottom-left, bottom-right corners |
| 3 | Inner top-left, top-right, bottom-left, bottom-right corners |

The atlas is intentionally terrain-only. Rooftops and village architecture use
their own free-placeable art so the terrain does not become repetitive or force
building silhouettes onto the collision grid.
