# Chamber Tile Folder

The root of this folder is reserved for the current gameplay TileSet resources:

- `cotfw_chamber_tileset_128_current.tres`
- `cotfw_chamber_tileset_256_current.tres`
- `cotfw_chamber_tileset_atlas_128_current.png`
- `cotfw_chamber_tileset_atlas_256_current.png`

Subfolders:

- `singles_current/`: the current individually cut platform, corner, T, and convex tile PNGs.
- `generated_versions/readable_passes/`: experimental readability-pass atlases and TileSets.
- `generated_versions/old_atlases/`: older atlas attempts and expanded variants.
- `diagnostics/`: comparison sheets and diagnostic images.
- `source_sheets/`: source sheets used to cut individual tiles.
- `singles_and_old/`: older single-tile cuts kept for reference.
