# Chamber of the First Weave Assets

Keep the root of this folder limited to assets that are actively used by the test world scene or are primary working assets.

- `Tiles/`: current gameplay TileSet atlases, physical single tiles, and active layer atlas TileSets.
- `atlas_guides/`: key/guide images that explain atlas regions.
- `generated_versions/source_images/`: generated source sheets, masks, and intermediate map outputs.
- `generated_versions/source_images/*_pre_alpha_cleanup.png`: backups of artist-updated source exports before local transparency cleanup.

Current scene-facing background and shrine PNGs live in this root folder so they are easy to find while tuning the scene. Placeable layer art for the test world is exposed through `Tiles/layer_atlases/`.
