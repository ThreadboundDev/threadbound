# Threadbound Woven Blue stamps

The library contains 36 new full-color stamps for the Blue blockout. It uses
bright yellow-green moss and leaves, coral blossom, warm cedar and sunlit
stone, with indigo roofing and turquoise water accents.

In Krita, open **Brush Presets** and choose **Threadbound - Woven Blue**. The
**Woven Blue - Terrain**, **Structures**, **Foliage**, and **Props** tags give
smaller selections. Single-click onto a stamp layer and use the toolbar Size
control to fit the piece. The default sizes are starting points for the 1:1
blockout. Keep foliage and props on their own layers when planning the
foreground. The PNGs can also be placed as individual image layers.

- [Catalog](catalog.jpg) shows the complete set.
- [Krita bundle](Threadbound_Woven_Blue.bundle) imports through **Settings →
  Manage Resource Libraries → Import**.
- [Transparent PNGs](stamps/) preserve the individual artwork.
- [Manifest](manifest.json) records the generation prompts, source sheet
  hashes, crop bounds, PNG hashes, and suggested brush sizes.

The palette references are Chase's November 21 screenshots of Ground A,
the blossom shrub, and the shoreline foliage. The original reference assets
are in the November 25 cleanup archive under
`Tracked/02 Unused runtime assets/Assets/BlueBiome/Art/WovenWorldChunks`.
The new stamp art was created in the built-in image generator. The sheet
revisions use the screenshots as color references.

Each preset embeds a link to its own RGBA brush tip. Its alpha and color
pixels match the corresponding standalone PNG. The terrain shelves use
irregular edges intended for overlapping and paint-over at joins.
