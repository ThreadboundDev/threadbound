# Blue Biome Art Sources

This folder contains editable and intermediate source artwork for the Blue Biome.
Game-ready exports belong under `Assets/BlueBiome/`; source sheets, keyed inputs,
and Krita documents belong here so Godot does not import them as runtime assets.

`KritaTerrainKit` is the active terrain source library. It contains the editable
3x3 terrain source and the stamp presets used to author the current runtime atlas.
Abandoned modular-terrain and grid-test families have been removed.
