# Carved cavern walkway stamps v3 — measured color match

November 2, 2026. Chase explicitly authorizes measured correction of existing
stamp pixels. This revision maps v2's RGB values to the C07_Inset_Cave_Face
reference already used in the room. It performs no image generation, spatial
filtering, redraw or resampling. Source dimensions, alpha bytes, silhouettes and
fully transparent pixels are identical to v2. The six shapes are retained.

Choose **Cavern - Carved Walkways v3** in Brush Presets after importing. The
presets retain the Village prefix required by the existing Stamp Controls plugin.
Flip X / Flip Y, Shift+X / Shift+Y and Reset retain compatibility. No plugin code
changes or new plugin installation is required. Earlier kits are retained.

`build_kit.py` requires NumPy and Pillow, v2 source PNGs, the v1 shared packer,
and the existing local C07 reference/plugin source. It computes an empirical
histogram transfer for each RGB channel using opaque pixels (alpha > 240).
Monotonic lookup tables are applied to all nontransparent pixels. The saved
source/output SHA256s and 256-entry lookup tables make the correction reproducible.
The original alpha and fully transparent pixels are retained exactly.

Validation checks the saved images against the RGB lookup tables, unchanged
dimensions/alpha/transparent pixels, monotonic channel order, exact serialized
brush pixels, bundle ZIP/resource integrity, and all 24 flip-state and
non-mirror-parameter preservation cases. Mean absolute RGB difference at six
reference quantiles falls from 4.50–15.83 in v2 to 0.06–0.39 on the 0–255 scale.
This measures channel distributions; it does not assert identical joint RGB
palettes or guarantee that every local join is visually seamless. Contrast and
color placement are preserved through monotonic mappings, but tonal spacing
changes as intended. Very faint alpha remnants from v2 are retained.

The 81-piece combined atlas is regenerated by
`tools/art/build_all_stamp_reference.py` into the existing ignored local painting
workspace's `all_current_stamps_2026_11_02_v3` folder. Each stamp remains on its
own layer, with background and labels separate. Earlier reference files remain.

**Existing painted marks are raster pixels and do not update when a brush is
replaced.** This kit changes future stamps and the separate reference atlas;
it does not automatically recolor or replace Chase's existing painting layers.
Game art, scenes and collision are not changed. Visual acceptance stays open
until Chase checks the new stamps at their actual intended scale and joins.
